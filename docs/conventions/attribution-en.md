# Attribution and roles

## Primary author

Viki P. Sitzer, @mvikips on GitHub, member of the @nepopetro organization.

Roles in the project:

- Data Architect: defines data architecture, schemas, modeling criteria and decisions on primary and secondary data sources.
- Stewardship: safeguards data quality, integrity and traceability. Responsible for personal data policies, source attribution and provenance documentation.
- Governance Tech Lead: defines and maintains repository conventions, project governance, contribution policies and technical acceptance criteria.

Unified designation in technical documents: Data Architect, Stewardship & Governance Tech Lead.

## How authorship is cited

In ADR and convention headers:

Author: Viki P. Sitzer (@mvikips). Roles in docs/conventions/attribution-en.md.

In codereviews:

Author and reviewer: Viki P. Sitzer (@mvikips). Roles: Data Architect, Stewardship & Governance Tech Lead.

In issues and PRs: authorship is recorded by GitHub through the author field. No explicit header is required.

## External contributions

Contributions by third parties are recorded in the author field of the corresponding PR or issue. Project authorship remains with Viki P. Sitzer. External contributions do not modify the primary attribution.

If an external collaborator contributes sustainably, they are added to this file with name, GitHub username and scope of contribution.
